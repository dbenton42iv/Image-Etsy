PRINT SIZES — 300 DPI JPG (RGB, max quality), white background, © Beech Creek Naturals 2026 on every design
Each design folder has 6 files. One file covers every print size of the same shape:

  24x36 (36x24 for wide designs)  2:3 ratio  -> 4x6, 8x12, 12x18, 16x24, 20x30, 24x36
  18x24 (24x18)                   3:4 ratio  -> 6x8, 9x12, 12x16, 18x24
  16x20 (20x16)                   4:5 ratio  -> 4x5, 8x10, 16x20
  11x14 (14x11)                   11x14
  A1 (A1_landscape)               ISO ratio  -> A5, A4, A3, A2, A1
  5x7   (7x5)                     5x7

FRAME / MAT MARGINS (updated Nov 2026)
Every file has an even white border on its tightest side, sized for framing and matting:
  24x36, 16x20 files ... 12.5% of the short side  (3.0" at 24x36, 2.0" at 16x20, 0.5" at 4x6 / 4x5)
  18x24, 11x14, A1 files ......... 10% of the short side (1.8" at 18x24, 1.1" at 11x14, 2.3" at A1)
  5x7 files ....................... 12.5% of the short side (0.625" at 5x7) for the trail maps
                                    (Bartram, Art Loeb, Mountains-to-Sea); other designs 10% (0.5")
Rule: at the SMALLEST size each file covers, the artwork AND the copyright line sit at least
0.5" from every paper edge, so a mat or frame lip (normally 1/4" overlap) never touches them
and at least 1/4" of white still shows inside the mat opening.
The previous 7%-margin versions are kept in _Previous_7pct_Margins.
Artwork is scaled to fit, never cropped.

All designs are rendered from vector masters (sharp at any size) except
Pack_Your_Dreams_Green (the original rectangular layout), which is a 5700 px raster:
~170 DPI of real detail at 36x24, 220+ DPI at 24x18 and smaller.

TEXT SIZE PER FILE (added Nov 24 2026) — Bartram, Art Loeb, Mountains-to-Sea maps
Small text no longer shrinks with the print. Each file's mileage table and copyright line are
sized for the smallest print that file is meant for, so they stay readable (target: table about
6 pt, copyright about 5 pt at that size). Tables keep their column layout and never overlap the
trail or labels; where a table needed more room it moved slightly (MST's table extends lower).
  File      sized for   Bartram   Art Loeb   MST      (table scale vs the master)
  7x5       5x7         1.4x      1.3x       1.5x     MST table ~5.3 pt (largest that fits)
  24x18     6x8         1.3x      1.1x       1.5x
  A1        A5          1.2x      1.1x       1.4x
  20x16     8x10        1.1x      1.0x       1.3x
  14x11     11x14       1.0x      1.0x       1.0x
  36x24     8x12        1.0x      1.0x       1.0x
Copyright line: about 5 pt at each file's smallest print size.
Art Loeb: DAVIDSON RIVER header on two lines; table right edge aligned with the copyright line.
MST: segment numbers ("1 ·") removed from the table; JOCKEY'S RIDGE header on two lines; table right edge
aligned with the copyright line; logo + title block lowered so its bottom lines up with the
bottom of the mileage table. The numbered markers on the map remain.
4x6 and 4x5 prints (from the 36x24 / 20x16 files) are too small for a mileage table to be
readable (about 3 pt). The buyer instructions recommend 5x7 or larger for these maps.
